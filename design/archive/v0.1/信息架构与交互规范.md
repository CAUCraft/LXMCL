## 1. 先按任务分区，再按熟练度展开

主导航固定为 **开始游戏、社团联机、我的游戏、资源中心**。账号与装扮、下载任务、设置、帮助和诊断使用固定辅助入口。不要把原文的“基础 / 高级 / 辅助”直接做成三个页面：用户通常知道自己要做什么，并不知道某个功能被开发者归为哪一类。

**首页不是控制台全集。** 只展示一个当前游戏、一个当前账号、一个主要启动动作与社团入口。Java、内存等只显示“已就绪 / 需处理”，点击后再进入相应设置。

### 几个容易混淆的边界

1. **资源中心 = 找到新内容；我的游戏 = 管理已经安装的内容。** 在我的游戏中点击“获取模组”，跳到资源中心并保留目标游戏与兼容筛选；安装完成后提供“查看已安装资源”。
2. **游戏版本不等于实例。** 面向用户统一叫“我的游戏”；在创建界面和帮助中解释“每个游戏拥有独立的版本、模组与存档”。高级文案可以补充“游戏实例”。
3. **材质包统一显示为“资源包（材质包）”。** 模组、资源包、光影、世界和整合包分开；皮肤与披风归账号装扮，避免误装进游戏目录。
4. **Java 是运行环境，不作为主导航。** 缺少环境时从启动任务内引导安装；完整版本列表在设置中。
5. **全局默认和当前游戏配置分开。** 实例设置每一项都显示“继承全局”或“已单独设置”，可逐项恢复继承。全局修改页提示已有多少个实例覆盖了这一项。
6. **启动器下载代理和游戏进程代理分开。** 前者在“下载与网络”；后者在当前游戏的高级运行设置。显示影响范围，避免用户改错对象。
7. **社团账号是明确的认证入口。** 在认证协议确认前，不把它写成“学校统一身份认证”，也不假定某种真实账号一定能进入某个服务器。

## 3. 关键交互路径

### A. 新用户第一次进入社团服

开始游戏 → 进入社团服 → 登录社团账号 → 检查是否有兼容游戏 → 显示需要准备的内容 → 确认 Java、游戏目录、大小 → 下载 → 检查 → 启动并进入。

- 已登录且已就绪：直接启动；按钮文字为“进入社团服”。
- 未登录：主要动作变成“登录社团账号”，成功后回到原任务。
- 无兼容游戏：提供“创建推荐游戏”，预填兼容版本，不先让新手理解所有加载器。
- 多个兼容游戏：推荐最近使用的一项，允许切换；不静默选取不明确的实例。
- 缺少 Java：默认推荐合适的 Zulu 版本，明确“版本、安装位置、大小”；使用自定义目录，确认后下载。
- 服务器维护：保留详情、公告、最近检查时间及重试；启动本地游戏仍可使用。
- 下载失败：停留在任务上下文，显示失败项目和重试 / 备用源；不用重新走登录流程。
- 认证过期：先说明账号状态，重新认证后回到原先服务器。

### B. 日常启动

首页检查当前游戏与账号 → 点击“启动游戏” → 单一进度状态：检查账号、检查环境、补全依赖、启动中、游戏运行中 → 按用户设置隐藏或保留启动器 → 游戏退出后恢复。

按钮的禁用、加载、失败状态都保留文字原因。启动过程中阻止重复提交；失败时展示具体原因、推荐修复、查看日志三个层次。示例：“当前游戏需要 Java 21，检测到 Java 17。选择兼容版本 / 下载 Java 21”。

### C. 安装线上资源

资源中心 → 选择目标游戏 → 根据版本与加载器筛选 → 资源详情 / 来源 → 安装前检查 → 变更预览 → 用户确认 → 下载 → 自动安装 → 跳转已安装资源。

依赖可自动加入安装清单，但必须在确认页可见。确定冲突和可能冲突使用不同措辞。无法判断时显示“尚未确认兼容性”，不显示虚假的绿色通过。禁用冲突项时保留文件；删除须单独选择。没有兼容版本时提供更换游戏或查看所有版本，不能静默安装最新版。

### D. 导入本地资源

点击导入或拖放 → 识别类型与文件数量 → 选择目标游戏 → 兼容性 / 重名检查 → 确认 → 导入结果。

多类型混合文件分组展示；无法识别的文件不默认当作模组安装。皮肤转到账号衣橱。已导入条目始终显示“用户自行导入”，在线更新按钮不可用并说明原因；“可启停、可删除”与“不可在线更新”并存。

### E. 全局搜索

Windows / Linux 使用 Ctrl K，macOS 使用 ⌘ K。入口常驻且可点击；当前列表的搜索只筛选该列表。

结果优先级：社团服务器 → 本地游戏 → 账号 / 角色 → 最近访问与设置 / 帮助 → 线上资源。每条结果统一为“类型图标、名称、匹配上下文、状态、明确动作”。不同类型的动作分别是“准备进入”“打开游戏”“切换 / 管理账号”“前往设置”“查看资源”。搜索服务器本身不隐式安装内容。

支持中文别名，例如“材质包→资源包”“钠→Sodium”。↑↓选择，Enter 执行，Esc 关闭并回到打开前的焦点。无结果显示可尝试的关键词；线上超时不影响本地搜索结果。

### F. 设置与诊断

普通设置默认收起高级项，按问题就近链接到需要的设置。全局与当前游戏都使用同一套字段组件，但作用域标签不同。涉及批量覆盖时先预览受影响的游戏。

下载失败可直达网络测试；启动失败可直达当前游戏日志；系统清理先检测再确认范围。不把内存清理描述为一定能提高 FPS。对于文档中尚未实现的 NBT 编辑、Windows 进程优先级等能力，不展示可执行的伪按钮。

| 适合 | 品牌展示、新用户与日常启动 | 模组管理、长期使用、较低视觉干扰 | 偏好暗色、关注联机与运行状态的用户 |
| 代价 | 需要额外验证模糊效果、可读性和渲染成本 | 品牌辨识度相对克制 | 需要补充各状态的暗色对比检查 |

推荐先以 **经典桌面** 作为交互基线，再把 **液态玻璃** 做成可选择的品牌风格。三版功能位置和语义尽可能一致，用户更换风格无需重新学习功能。极简深色提供低干扰的第三个视觉方向用于比较。

液态玻璃的目标是层次、高光、透明和背景折射感。本轮用半透明面板、模糊和高光表达；没有承诺复制 Apple 的特定系统材质或真实动态光学折射效果。Slint 的最终效果、平台差异与性能需要后续 UI 技术验证。关闭透明度后应自动切换为实色高对比面板，功能与布局保持可用。

参考 SJMCL 的部分是顶部导航、上下文分栏和列表管理的熟悉感。未使用其标识、源码或整套视觉资产。官方新手文档展示了“实例 → 添加 / 导入 → 版本 → 加载器 → 位置 → 下载 → 启动”的任务链，可作为传统启动器交互的对照：[SJMCL 新手指南](https://mc.sjtu.cn/sjmcl/en/docs/beginners-guide.html)。

## 5. 组件与可用性规范

- 桌面基准：1440 × 900。正式布局建议最小 1040 × 700；宽度不足时隐藏侧栏说明文案、资源卡片三列变两列，右侧启动配置合并到主区域。窗口更小时允许内容区滚动，主操作保持可达。当前 HTML 以整稿缩放供评审，不代表响应式实现已完成。
- 8 px 间距体系；面板内边距 24 px；标题 28–38 px；正文建议 14–16 px；辅助信息 12–13 px。截图中的较小辅助字号还需在真实显示器上按 100% / 125% / 150% 缩放验证。
- 常规按钮高度 44 px；列表内紧凑动作 34–38 px；图标按钮需完整标签 / Tooltip，触发区建议不小于 32 × 32。主要操作同一区域保持一个。
- 图标统一 20–24 px、约 1.7 px 描边。不要仅用图标表达安装、删除和异常状态。
- 状态至少包含：默认、悬停、按下、键盘焦点、禁用、加载、成功、警告、失败。颜色以外增加文字和图标。
- 正文目标对比度至少 4.5:1，大字号至少 3:1；透明材质应按最不利背景检查。光效不能穿过正文造成辨识下降。
- 键盘可达：Tab / Shift Tab 顺序与阅读顺序一致；Enter 执行；Space 切换；弹窗圈定焦点；关闭后恢复焦点。正式实现须支持读屏和语义标签。
- 对话框避免超过两层；超过一个复杂操作改用向导或独立详情页。确认按钮写清结果，例如“禁用冲突项并安装”，不用笼统“确定”。
- 动效建议 120–200 ms，界面位移小于 12 px；尊重系统减少动态效果设置。下载进度使用真实任务比例，不用模拟进度掩盖等待。
- 设置“减少透明度、减少动画、字号、字体、浅色 / 深色 / 跟随系统、壁纸”均可独立配置。皮肤预览有静态回退，长时间失败不阻止其他账号操作。

## 6. 空态、异常态和恢复路径

| 场景 | 必须展示 | 主要动作 | 保留的上下文 |
|---|---|---|---|
| 无游戏 | 原因说明 + 创建 / 导入两个入口 | 创建推荐游戏 | 服务器或资源安装目标 |
| 无账号 | 账号类型及用途 | 登录社团账号 / 添加账号 | 原入服任务 |
| Java 缺失 | 所需版本、推荐发行版、大小、路径 | 安装兼容 Java | 当前游戏 |
| 认证过期 | 哪个账号过期 | 重新登录 | 服务器、角色与游戏 |
| 无网络 | 本地游戏仍可使用，线上功能不可用 | 重试连接 | 本地列表与已有任务 |
| 服务器维护 | 维护状态、公告、检查时间 | 重试 / 启动本地游戏 | 当前选择 |
| 无兼容资源 | 当前版本 / 加载器条件 | 更换目标 / 查看其他版本 | 搜索词与来源 |
| 下载失败 | 失败文件、来源、可恢复状态 | 重试 / 备用源 / 网络诊断 | 已下载内容与依赖 |
| 资源冲突 | 涉及项目、依据是否确定、建议变更 | 预览处理方案 | 目标游戏和原文件 |
| 磁盘空间不足 | 需要与可用空间、当前目录 | 更换位置 / 稍后继续 | 待下载清单 |
| 删除游戏 | 游戏名、包含的存档、可恢复与否 | 明确确认删除 | 其他游戏 |
| 游戏崩溃 | 用户可读摘要、建议、展开日志 | 推荐修复 / 导出诊断包 | 上次启动配置 |
