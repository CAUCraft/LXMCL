# 早期 Slint 截图归档

本目录保存首次品牌接入与像素玻璃迭代时的界面截图，不代表当前版本，也不作为最新功能验收证据。

- `brand-home-light.png` / `brand-home-dark.png`：早期品牌首页的浅深色状态。
- `pixel-glass-stepped-home.png`：阶梯玻璃表面方案。
- `pixel-glass-fusion.png`：导航融合效果记录。

这些截图早于孪枭正确 RGBA 双层皮肤、新手向导和启动检查页的完成；其中的旧称呼、皮肤表现和“启动游戏”等文案已变更。当前实现以 [UI 规范](../ui/README.md) 和 `ui/` 源码为准；后续验收应重新截取实际窗口，避免用历史图冒充现状。
