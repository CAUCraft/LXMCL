# 按钮、新手流程与帮助规范

更新：2026-10-27。依据原始功能需求，以及本轮对 XMCL / SJMCL 官方资料的查阅。原始需求文件未改动。本文的“接口”指 Rust 前端与应用服务之间的能力边界，不是网络监听端口。

**开发约束：项目自己维护的应用实现与新工具统一使用 Rust，继续使用 Slint；第三方依赖的内部语言不受限制。先完成可操作、可验证的前端，再接真实认证、下载、文件操作与游戏进程。** 现有历史设计资产和辅助脚本不在本轮迁移范围。

## 1. 页面层级与按钮责任

沿用 [信息架构与需求映射](information-architecture.md)：开始游戏、我的游戏、社团联机、资源中心为日常入口；下载任务、账号与装扮、设置、诊断与工具、帮助作为固定辅助入口。高级参数放在所属任务的“高级”折叠区，避免再新增一个混杂的“高级功能”总页。

### 按钮统一规则

- 主按钮用“动词 + 对象 / 结果”：检查并启动、创建独立游戏、安装到此游戏、重新登录、重试失败项。不能用含义模糊的“确定”承担安装、删除或覆盖。
- 每个操作区域仅突出当前下一步。选择状态可用描边 / 标签表达；删除不用普通安装按钮的主强调色。
- 按钮可用性来自状态，而不是直接推断标签。禁用旁说明原因；后端再次校验，不能只依赖前端灰掉按钮。
- 发出请求立即进入忙碌状态并禁用重复提交；长任务允许离开页面，并通过任务中心追踪，不锁住整个窗口。
- 创建 / 安装 / 修改前先显示目标。取消准备清单不执行；取消进行中的任务保留可恢复进度；删除内容另走明确确认。
- Toast 只反馈轻量成功。需要用户处理的错误留在页面内，带重试 / 教程，不在几秒后消失。
- Tab / Shift+Tab 移动焦点，Enter / 空格激活聚焦按钮，Esc 关闭浮层；危险确认不绑定输入框 Enter。Ctrl+K 打开全局搜索，F1 打开上下文教程。

| 场景 | 默认按钮与前置状态 | 忙碌 / 失败 / 完成 | 取消与防呆 |
|---|---|---|---|
| 首页启动 | 检查并启动；已有游戏与身份 | 检查中 → 有问题 / 需准备 / 就绪 → 启动中 → 游戏运行中 | 不用一个布尔值把“进程已创建”当作“已入服” |
| 社团服务器 | 准备并进入；固定服务器 ID | 找兼容实例 → 核对差异 → 准备 → 启动；入服成功由真实事件确认 | 不覆盖其他实例，不把离线身份当作社团登录 |
| 创建游戏 | 创建独立游戏；名称、版本、目录有效 | 准备清单 → 任务；失败保留草稿 | 原版默认不装加载器；快照版单独标注 |
| 账号登录 | 登录微软 / 登录社团 / 添加本地身份 | 等待授权 → 验证中 → 成功或需处理 | 不收集统一的“万能账号密码”；取消认证不丢目标 |
| 缺 Java | 查看准备清单 | 确认来源及位置 → 准备中 → 重新检查 | 优先复用，默认推荐 Zulu；未知版本不能写成匹配 |
| 安装资源 | 安装到“游戏名”；类型与版本兼容 | 依赖 / 冲突清单 → 下载 / 校验 / 安装 → 查看已安装 | 已安装显示状态；重复任务打开原任务；目标固定 |
| 整合包导入 | 创建独立游戏 | 识别格式 → 预览内容 → 导入 | 不能当普通 mod 丢入当前实例；拒绝路径穿越 |
| 本地导入 | 识别文件 → 确认类型和目标 | 导入摘要与失败项 | 不仅按扩展名识别；皮肤转账号页，来源记为用户导入 |
| 模组启停 | 启用 / 停用；显示作用游戏 | 本地变更结果；有依赖时列出受影响项 | 不自动删除依赖；可逆操作给撤销 |
| 在线更新 | 查看更新清单 | 备份 / 替换 / 校验 → 完成；失败可恢复 | 自行导入且来源未知则不可更新，不能假装“已最新” |
| 删除游戏 | 更多 → 删除 | 明确名称、目录、存档数量与保留选项 | 默认取消；真实删除前提供备份 / 回收站；不静默递归删除 |
| 下载任务 | 暂停 / 继续 / 重试失败项 | 分阶段显示，未知总量用不定进度 | 取消与清除历史分开；清除记录不删游戏 |
| 设置覆盖 | 改为单独设置 / 恢复继承 | 显示全局值与最终有效值 | 恢复单项，不重置其他项；有未保存更改时提示去向 |
| 诊断与工具 | 检查此游戏 / 测试连接 | 分服务结果、时间戳、下一步 | 不默认清内存或清 DX 缓存；说明影响并要求用户主动操作 |
| 在线更新启动器 | 查看更新 → 安装并重启 | 校验 → 等待安全退出 → 替换 → 重启结果 | 有活动任务时推迟；保存状态并允许恢复 |
| 外部调用 / MCP / 扩展 | 默认未启用 → 查看能力 → 启用 | 权限范围、来源、执行状态 | 外部调用和界面使用同一校验与确认逻辑，不能绕过删除 / 执行命令确认 |

## 2. 新手主流程

### 首次游玩向导（当前前端可体验）

1. **选玩法**：社团 / 自己玩；选定游戏或进入创建。解释“每个游戏是独立的版本、模组与存档集合”。社团要求从服务器清单取得，当前显示示例。
2. **确认身份**：展示账号名称、类型和认证状态；到账号页处理登录，不在向导中嵌入另一个密码表单。
3. **存储与环境**：分别编辑游戏 / Java 目录；逐字段说明错误；支持中文空格。真实服务接入后检测空间与权限，在确认前不写入。
4. **检查启动**：展示目标、账号、玩法、目录，再进入检查。需要环境时先看清单；完成不自动绕过其他阻断项。

当前可“稍后继续”，会话内草稿保留；帮助文章可返回原步骤。正式首次启动应以没有配置 / 没有实例为依据展示向导，允许跳过，并在首页保留“继续准备”；不对熟练用户每次强制展示全屏教程。

### 关键失败分支

| 状况 | 面向用户的说明 | 下一步 | 禁止的错误行为 |
|---|---|---|---|
| Java 缺失 | 这个游戏还缺少匹配的运行环境 | 核对 Zulu 清单与目录，确认准备 | 一开始就让新手填 JVM 参数；无确认安装到 C 盘 |
| 登录过期 | 当前身份需要重新验证 | 去账号页，返回同一启动目标后重查 | 自动切换离线身份或重复重试到无穷 |
| 服务器要求不匹配 | 当前游戏与服务器版本 / 加载器不同 | 选择兼容游戏或创建副本 | 改写原实例并影响存档 |
| 下载失败 | 指出哪一步、哪个源失败 | 重试失败部分、检测连接、选择备用源 | 从头新建多个重复下载 |
| 空间不足 / 无权限 | 明确目标目录与所需空间 | 换目录 / 释放空间后重试 | 把路径语法检查说成可写性检查 |
| 资源依赖缺失 | 明确必要和可选依赖 | 必要项随计划准备，可选项用户决定 | 不经解释改变用户配置 |
| 检查结果未知 | 暂时无法确认，不等于通过 | 重试、展开详情、教程 | 显示绿色“正常”或允许直接启动 |
| 修改配置后仍有旧结果 | 检查结果已过期 | 重新检查，生成新的准备清单 | 套用另一个账号 / 游戏的就绪状态 |

## 3. 帮助、教程与逐步引导

内置手册围绕八个任务：第一次玩、社团入服、账号选择 / 过期、Java、存储、资源类型、网络下载、启动失败。每篇固定包含“这篇解决什么 → 三个操作步骤 → 当前能力边界 → 前往操作”。教程不只解释术语，要能返回刚才的游戏或准备流程。

帮助分三层：控件旁一句解释、遇到问题时的对应教程、完整手册目录。仅首次或卡在某步骤时出现提示；不把整页引导气泡盖住所有按钮。高阶术语在展开后解释；JVM / Metaspace / 包装命令不进入普通新手步骤。

搜索共享中文别名，例如材质→资源包、Mod→模组、进服→社团联机。无结果时给示例词和清空入口。教程内容通过稳定 ID 与错误绑定，避免改标题后关联失效。后续图文教程由版本化内容随应用打包，联网 Wiki 是可选扩展；基础帮助离线可读。


服务边界独立维护于 [接口与状态约定](service-contracts.md)；验证记录和下一步见 [接力开发](../development.md)。
