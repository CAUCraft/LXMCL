# 视觉、动效与渲染规范

目标是可读、响应快的 Minecraft 桌面工具，以及可选择的像素玻璃质感。大学 / 社团身份通过原始标识表达，不添加飞机、航线、跑道、仪表盘或航天意象。

## 风格与组件

经典与像素玻璃共享页面、动作和数据，切换风格不重置当前游戏、账号或导航。正文使用正常中文字体；像素感来自 16 × 16 图标、皮肤和阶梯轮廓，不用像素字体降低长文可读性。

优先复用 [components.slint](../../ui/components.slint) 的 `AppButton`、`Panel`、`Label`、`Muted`、`Heading`、`Badge`。常规按钮当前为 36 px，首页主动作 44 px，侧栏导航 40 px；正文 14 px、辅助文字 12 px、标题约 25 px。这些是现有基线，长文、缩放和触控适配仍应按场景调整，不能把旧 Figma 尺寸直接搬回当前组件。

玻璃面板由 [pixel-glass.slint](../../ui/pixel-glass.slint) 的阶梯矩形、像素边缘与分段高光组成。当前没有实时模糊、光学折射或系统级透窗。搜索、对话框与重要消息使用实色底，避免视频或背后文字影响辨认。焦点描边、状态文字不能被材质层遮住；错误、禁用和成功不能只靠颜色表达。

## 色彩与明暗切换

统一从 [theme.slint](../../ui/theme.slint) 读取语义颜色，不在各页面分别定义一套浅深主题。

| Token（经典基线） | 浅色 | 深色 | 用途 |
|---|---|---|---|
| canvas | `#f3f5fc` | `#111726` | 窗口背景 |
| solid-panel | `#ffffff` | `#1b2335` | 实色表面 |
| text | `#202b48` | `#edf1fc` | 正文 |
| muted | `#6c7896` | `#a4b0cd` | 辅助信息 |
| accent-fill | `#4b5c9f` | `#6579c9` | 主按钮 |
| green | `#327b57` | `#82d6ad` | 就绪 |
| amber | `#926126` | `#e8bd7d` | 待处理 |
| danger | `#bd4141` | `#ffa2a2` | 错误 / 危险操作 |

像素主题覆盖部分表面透明度和辅助文字色，实际值以源文件为准。`Theme.dark` 只是目标状态；颜色通过 `Theme.darkness` 统一插值，360 ms ease-in-out。`tone(day, night)` 使用 Slint 的 `night.mix(day, darkness)`，不要反写权重。静态背景双图交叉淡化；导航纹理的 RGBA 与主题同步。

启动直接采用已保存主题，首轮布局后才启用过渡；连续切换从当前状态反向。原生控件的 `Palette.color-scheme` 仍按布尔状态切换，不能宣称所有内部控件均已平滑插值。

## 像素玻璃导航

[pixel_motion.rs](../../src/pixel_motion.rs) 在 4 px 网格生成局部透明纹理：旧选中块与新选中块连接、融合、收颈、分离，280 ms 落定。内容页面立即响应点击，不等待动画。连续点击仅更新最新目标；结束后停止计时器，不累积动画队列。

初始几何需等待布局结果（当前一次 32 ms 同步）；忽略尚未布局的无效目标。改导航尺寸或间距时，同时验证反向与长距离跳转的画布边界。

## 孪枭与双层皮肤

唯一当前皮肤是 [luanxiao.png](../../ui/assets/luanxiao.png)：64 × 64 RGBA、经典 4 px 手臂。旧 `club-skin.png` 实际是无透明通道的 JPEG，仅为历史参考；不能据白色抠图或重新作为当前贴图。原始 Logo 与皮肤保持字节不变，派生资源另存。

[skin_preview.rs](../../src/skin_preview.rs) 使用 280 × 400 正交 CPU 光栅化、深度缓冲、背面剔除与最近邻采样。六个基础部件与六个外层分别建模：帽层外扩 0.5 模型单位，躯干和四肢外扩 0.25，UV 仍按基础尺寸取样。头部两层共用 `[0, 24, 0]` 颈部转轴。透明像素跳过；当前素材是二值 alpha，通用半透明混合、披风和 slim 模型尚未完成。

[mascot_motion.rs](../../src/mascot_motion.rs) 将身体侧转限制在 ±24°、头部偏航 ±34°、俯仰 ±26°。头部响应约 55 ms、身体约 95 ms，16 ms 计时器只在姿态变化时运行；覆盖旧鼠标目标，不排队重绘。跟随原点随滚动和窗口变化重新计算。离开主页、打开浮层、移出内容区或最小化时停用或回正；装扮页手动旋转与主页姿态独立。命中区域不能抢走按钮点击和滚轮。

## 壁纸与性能

七段视频为 1280 × 720、24 fps、静音循环，封面为 480 × 270 JPG。视频经 Git LFS 提供，封面为普通 Git 文件。缺文件或解码失败保留静态封面。当前资源位置与来源见 [素材说明](../../ui/assets/README.md)。

[wallpaper.rs](../../src/wallpaper.rs) 用独立线程读取 FFmpeg RGB24 管线，队列只保留最新帧；暂停 / 最小化阻塞解码，切换视频和退出结束对应子进程，UI 不同步等待进程回收。Windows 子进程隐藏窗口。当前不是硬件解码，也没有零复制视频上传。

GPU 默认 FemtoVG / OpenGL，开发 profile 已优化。模型同步保留 `VecModel` 身份，只改变化行；主题 / 弹窗切换不能触发全部资源列表重建。增加动效先评估是否需要独立计时器，优先复用现有时间轴并在静止时停表。

性能记录位于 [docs/performance](../performance)。CPU 皮肤渲染、导航回调、开始绘制与提交耗时是不同指标，不能改名为端到端输入延迟或游戏 FPS。尚未完成的减少动画、跟随系统明暗、读屏和多 DPI 验收见 [验证记录](../validation.md)。
