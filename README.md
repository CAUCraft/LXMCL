# LXMCL

CAUCRAFT 的 Minecraft Java 版原生启动器，基于 Go、MyGo 和 Lobe MyGo，支持 1.20.1 及之后的正式版本。

## 下载

Windows x64 开发版在 [GitHub Actions](https://github.com/CAUCraft/LXMCL/actions/workflows/ci.yml?query=branch%3Amain)。打开最近一次成功的 `main` 构建，在 **Artifacts** 下载 `lxmcl-windows-amd64`。解压后可直接运行 `LXMCL.exe`，也可使用其中的安装程序。发布版本见 [Releases](https://github.com/CAUCraft/LXMCL/releases)。

## 快速开始

1. 在首页点「切换账号」，选择 Microsoft、第三方皮肤站（Yggdrasil）或离线账号。
2. 打开「下载 → 游戏版本」，选择原版、Fabric、Forge、NeoForge 或 Quilt。可选已有分组，默认未分组。点「安装实例」，或点「仅创建实例」并在实例概览按需下载或校验游戏文件。
3. 在主页选择实例，点「启动游戏」或「下载并启动」。首次启动会校验并补齐游戏文件。

Windows x64 会优先使用兼容的本机 Java，必要时下载官方运行时。也可在设置中指定 Java。启动失败后，可在任务中心查看日志或重试。

在「实例 → 概览」查看实例 ID。例如，在 PowerShell 中运行 `.\LXMCL.exe --launch 2` 即可用当前账号启动 ID 为 2 的实例，结果可在任务中心查看。启动器已打开时由现有窗口处理，主页的启动目标保持原样。在 Windows 的实例菜单中选择「创建启动快捷方式…」，选好保存位置后即可从 `.lnk` 打开该实例。同名文件会保留。

## 常用功能

- 在**实例页**调整启动设置、更换游戏版本和加载器、复制实例和管理模组、资源包、光影。模组列表可离线读取 JAR 名称与版本，支持按模组 ID 搜索。在「资源 → 模组」选择「比对实例模组」，可离线查看对照实例相对于当前实例的新增、缺少、版本和启用状态差异。没有声明 ID 的文件按完整文件名比对。点「复制差异清单」可手动分享双方游戏与加载器版本、模组差异及未能配对的标识。勾选本地模组后可用「复制到实例…」选择相同游戏版本和加载器的已有实例，预览后复制并保留启停状态。同名文件和重复模组 ID 会跳过，前置模组需自行核对。用「备份 ZIP…」可将勾选的模组写入自选的新 ZIP，归档内的 `mods/` 目录保留原文件名及停用后缀。要恢复时，在目标实例的模组页点「从备份恢复…」，预览并勾选要恢复的文件。同名、相同模组 ID 或无法识别的条目会标出并跳过。「检查更新」后可在单个模组旁点「跳过此版本」或「恢复提示」。跳过只对当前实例和该次更新生效，后续新版本仍会提示。可将本地文件拖入当前分类、批量启停、自选排序，或按实例版本从 Modrinth 添加资源。在「下载 → 模组」切换到 CurseForge，填写 API Key 后可查看必需前置并安装所选文件。下载页支持保存到文件夹、加入队列，重启后可继续下载。
- 在**实例 → 资源 → 资源包**点「预览」可离线查看 ZIP 或目录包内的封面、说明和声明格式。目录包需在顶层包含 `pack.mcmeta`。「游戏上次选择」按本实例 `options.txt` 的保存顺序列出资源包，可查看本地匹配项、内置标识和缺失项。
- **整合包**可从 Modrinth 或 CurseForge 在线安装，也可导入本地 `.mrpack` 或 CurseForge `.zip`。安装到新实例时可选择已有分组，默认未分组。可在实例菜单导出 .mrpack，或从[服主订阅](docs/development.md#服主整合包订阅)安装并预览后续更新。更新保留同名资源的启停状态。模组更换文件名时按清单 ID 匹配。CurseForge 在线查询及依赖下载需要 API Key。
- 在实例菜单的**更换图标**中预览本地 PNG，应用到实例列表和概览，也可恢复加载器默认图标。
- 在实例菜单的**设置分组**中创建或选取分组，也可将实例移回未分组。在分组筛选菜单点「批量设置分组」，可勾选当前列表中的多个实例一起移入已有分组或移回未分组。复制实例时可为副本选择已有分组，默认未分组。实例列表可组合使用 Minecraft 版本、加载器、分组、搜索词和缓存筛选，重启后会记住版本、加载器和分组。版本按本地实例的完整版本号精确匹配，包括快照。选择「未识别」可查看加载器未知的实例。
- 实例列表可选默认顺序、按名称、最近游玩或累计时长排列，记住上次选择的顺序。
- 在**实例 → 概览**查看上次游玩和累计时长。启动器在本机记录游戏进程实际运行的时间，先关闭启动器时计到关闭为止。
- 在**实例 → 概览**添加多行备注，记录进度、坐标或下次游玩的计划。
- 在**实例 → 导入本地实例**选择 Prism Launcher 或 MultiMC 的原版实例目录或本地 ZIP。ZIP 可直接包含实例文件，也可在一层子目录中包含实例。预览 Minecraft 版本后，可选择已有分组（默认未分组），设置存档范围，并勾选要带入的游戏选项和游戏内服务器列表。服务器列表默认不勾选，勾选后只将 `servers.dat` 复制到新实例。存档可选全部导入、只导入所选或不导入。只导入所选时在预览内勾选目录，复制范围仅含这些目录及各自内容。更换来源后需要重新勾选。确认页可预览并复制拟写入的新实例目录。兼容的内存上限和窗口尺寸也会带入新实例。源目录或 ZIP 保留，游戏本体按普通实例流程安装。原版实例菜单中的「导出实例 ZIP」可将名称、版本和兼容的内存及窗口配置写入新文件。存档默认不包含，也可选全部或只导出勾选的世界。存档仅带入原版世界数据，数据包、额外文件及启动脚本留在原处。勾选「游戏内服务器列表」会将当前实例的 `servers.dat` 和其中的地址写入本地 ZIP，默认不勾选。
- 在**实例 → 截图**按修改时间浏览游戏截图，点击预览可查看大图，用左右方向键切换，按 Esc 回到打开时的选中项和列表位置。点「复制图片」将原尺寸截图放入系统剪贴板，打开截图文件夹，或将选中的原始 PNG 导出到其他目录。复制实例时可分别勾选模组、资源包和光影包，也可单独勾选「游戏截图」，将图库中的 PNG 连同原修改时间带入副本。也可单独勾选「游戏内服务器列表」带入该实例的 `servers.dat`；整套复制已包含此文件。
- 在**实例 → 游戏文件 → 浏览存档**可按游戏内世界名或目录名搜索存档，并查看上次游玩时间。列表默认按目录名排列，也可切换为「最近游玩」，时间未知的世界排在最后。缺少名称时显示目录名，缺少时间时显示「未知」。选中世界和预览复制时，会分别显示 `level.dat` 中记录的保存版本和实例配置版本。无法读取保存版本时显示「未知」。选中世界后会显示本地缩略图，缺失或无法读取时显示文件夹图标。点「计算大小」可查看当前世界可备份文件的数量和未压缩总大小。选中可见条目后，可点「打开世界目录」在文件管理器中查看。点「进入世界」可直接启动该实例的单人世界，也可点「备份所选世界」为它单独创建可恢复的 ZIP。点「复制世界」可预览并复制到游戏版本和加载器一致的另一现有实例，模组实例还须使用同一加载器版本。同名目录会另存为新目录。点「查看数据包」可浏览所选世界的本地 ZIP、文件夹或未识别条目，以及存档上次记录的启用和停用列表。本地缺失和来源不明的标识会单独标出。快速启动采用版本元数据声明的参数；缺少支持时仍可从实例页正常启动。
- 在**游戏文件**页创建存档 ZIP，从最近备份、全部本地备份列表或本地 ZIP 选择恢复。全部列表按时间排列，可按文件名搜索，匹配时忽略大小写。丢失的文件会在仍有对应任务记录时标出。在全部备份列表点「导出」可将该 ZIP 原样保存为指定的新文件。可从任务中心的已完成备份任务直接查看其 ZIP 的只读预览。预览含多个世界的 ZIP 时可按世界目录名搜索，并查看各世界可恢复文件数及 ZIP 目录声明的未压缩大小。「全部世界」仍对应完整归档。整份 `saves` 目录可按世界选择恢复。单世界 ZIP 若直接包含 `level.dat`，则以压缩包文件名恢复。同名世界另存为副本。
- 在**账号中心**预览皮肤和披风，Microsoft 账号可上传 PNG 皮肤。通过**联机**页收藏、编辑或临时直连服务器，查看公告、版本、人数和延迟。启动器收藏支持按名称或地址搜索。列表上方的箭头可调整当前可见收藏的顺序。「备份与恢复」可将完整收藏按顺序导出到本地 JSON，或预览备份后追加新地址；同址旧收藏保留原名和位置。切换到「游戏内收藏」可离线查看所选联机实例的 `servers.dat`，按游戏顺序浏览名称和地址。可手动刷新、用该实例启动并加入所选服务器，或勾选条目并确认导入启动器收藏。直连使用版本元数据声明的 Quick Play 多人参数。已收藏的同址条目保留原名称和顺序。本次运行的联机实例可跟随主页或单独指定。
- 在**日志与崩溃报告**中搜索、筛选、复制和导出启动日志、游戏日志（含调试及压缩归档）和崩溃报告。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+K | 搜索实例 |
| Ctrl+J | 任务中心 |
| Ctrl+F | 在当前日志或崩溃报告中搜索 |
| F2 | 重命名当前浏览实例 |
| Esc | 关闭弹窗或返回 |
| F1 | 关于与版本信息 |

## 开发

安装 [Go](https://go.dev/dl/)（版本见 [go.mod](go.mod)），在仓库根目录运行 `go run . -data-dir .local/dev`。构建与测试见[开发指南](docs/development.md)，模块边界见[架构](docs/architecture.md)。
