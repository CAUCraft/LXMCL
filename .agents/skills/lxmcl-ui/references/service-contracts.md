# 呈现契约与业务状态

本文件规定 UI 如何理解业务数据、准备报告和任务状态。工程边界与未来任务订阅见[架构设计](../../../../docs/architecture.md)，当前能力见[开发指南](../../../../docs/development.md)。真实状态以服务结果为准，页面不自行推断成功。

## 已有契约

准备流程定义于 [contracts.rs](../../../../src/contracts.rs)，当前由 [preview_services.rs](../../../../src/preview_services.rs) 内存实现，经 [journey.rs](../../../../src/journey.rs) 适配。设置、实例记录与 Java 探测见 [launcher-api](../../../../crates/launcher-api/src/lib.rs)，这些提供者已有真实本机能力，但尚未组成真实启动流程。

| 类型 | UI 必须保留的含义 |
|---|---|
| LaunchContext | 捕获实例 ID、名称、修订、账号 ID、游戏 / Java 目录、版本 / 加载器及启动目标；不含令牌 |
| InstanceRecord | ID 标识实例，revision 标识配置版本；创建记录不代表已安装游戏 |
| JavaCandidate | 探测到版本、厂商和架构，不等于已验证所有游戏兼容条件 |
| CheckReport / CheckItem | 报告绑定目标；来源 Preview / Live；Ready、NeedsAction、Blocked、Unknown 分开显示，未知不视为通过 |
| PreparationPlan / PlannedChange | 说明具体变更、来源与路径；下载字节数未知显示待估算，不填 0 |
| ApplyPlanRequest | 请求、报告、计划 ID 与目标一起提交；取消确认不提交 |
| LaunchRequest / LaunchReceipt | 回执保留目标和来源；Preview 不代表创建游戏进程，创建进程也不等于进入服务器 |
| ServiceError | 错误类别、用户说明、重试能力与关联教程；技术日志可展开，不靠解析文字分支 |

当前准备演示会比较目标和修订，并处理会话内重复请求；不能据此宣称已有持久化幂等或崩溃恢复。实例修订为 u64，在 Slint 适配处以十进制字符串传递，避免整数截断。版本 / 加载器标签、列表位置和名称都不能替代唯一实例 ID。

## 展示与草稿

业务快照由应用层构造，Presentation 保存草稿与导航，Slint 模型只作投影。迁移前保留现有契约的目标绑定；迁移后也不能从可编辑显示字段拼接执行目标。

- 全局默认、实例覆盖和最终有效值分开呈现；恢复继承删除覆盖项，不复制一次全局值后冒充继承。独立覆盖目前仍是目标交互。
- 资源种类区分模组、整合包、资源包、光影、世界、皮肤和披风；自行导入标明来源，不能靠名称推断在线更新能力。
- 兼容、已安装、可更新是独立状态；Unknown 显示原因。路径使用服务返回的实际目标，时间按本地时区格式化，容量按整数 bytes 转换，未知延迟不填零。
- 搜索结果携带对象类别、稳定目标与类型化动作；旧整数 / 负数路由只留在兼容适配中。
- 成功与失败都关联捕获对象。切换实例不能将旧回调的成功、失败或准备报告套给新选择；离页不等于撤销已接受写入。

## 准备、启动与长任务

启动呈现遵循：检查 → 需处理 / 等待确认 / 就绪 → 准备 → 重新检查 → 启动中 → 运行 → 退出。真实进程创建后才能进入运行状态；入服结果需要可验证事件。演示流程明确标注来源，不使用定时器宣称真实成功。

长任务区分等待、运行、等待用户、失败、取消、成功；只有服务支持暂停时显示暂停 / 继续。下载、校验、安装分别显示阶段，下载 100% 不等于安装完成。终态不能被迟到进度覆盖，重试展示新 attempt，仍指向原目标。

页面通过一次 watch 取得一致快照与后续事件，重新进入或订阅落后时重新 watch；不能先取快照再另行订阅造成空档。该任务机制是待实现设计。关闭页面只释放订阅，主动取消检查、取消下载、停止游戏分别是明确命令。

安装、覆盖、删除与自定义执行命令说明目标及后果，按具体变更计划确认。普通草稿、重命名和设置不追加通用计划弹窗。计划过期时重新检查；外部调用走相同用例，不能跳过必要确认。

## 错误与帮助

UI 需区分认证过期、权限不足、版本不匹配、缺 Java、依赖缺失、网络超时、校验失败、空间不足、无写入权限、实例忙碌、计划过期、已取消和不支持。实际错误类型按接入功能逐项定义，不预建空服务。

错误关联稳定教程 ID：`start`、`club`、`account`、`java`、`storage`、`resources`、`network`、`launch`。教程返回同一任务与目标；技术详情与账号秘密分离，令牌不进入页面模型或日志。
