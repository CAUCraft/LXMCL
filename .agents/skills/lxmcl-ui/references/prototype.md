# 日光 04 参考原型

[index.html](../assets/prototype/index.html) 是已批准的独立 HTML / CSS / JS 原型，双击即可在浏览器打开。所有业务数据留在页面内存，只用于对照布局与交互；原生产品使用 Rust + Slint。

唯一视觉规范是 [REDESIGN](REDESIGN.md)。本原型保留首页风格参考；内部工作区的密度、选择与详情分离、紧凑对话框及社团延期以当前规范和原生代码为准。原型的 CSS 模糊和 DOM 动画不是原生实现要求，不能用原型演示推断真实服务、Windows 窗口行为或帧时间已验收。

## 使用

默认铺满预览窗口。品牌旁的「预览」入口提供场景、速度和控件样本；可查看缺实例、Java / 认证 / 准备失败等分支。Ctrl+K 搜索、F1 帮助、Esc 关闭浮层、Alt+Left 返回。

背景、Logo 和皮肤直接引用仓库 [ui/assets](../../../../ui/assets)，不维护另一份素材副本。移动原型后应检查相对资源路径。原型无需本地服务或联网，不在开发指南保留临时 localhost 地址。

## 文件职责

| 文件 | 责任 |
|---|---|
| controls.js / controls.css | 共享控件、状态与键盘语义 |
| workspace.css | 日光 04 工作区、唯一上下文栏、居中浮层 |
| motion.js | 有限动画、当前值接续、退场层与减少动态效果 |
| desktop.js | 示例状态、页面和交互流程 |
| desktop.css | 基础与专用内容布局 |

原型中的安装、认证、目录、下载与窗控都是演示；独立实例覆盖和扩展页面不表示原生应用已有对应实现。实际边界见[开发指南](../../../../docs/development.md)。
