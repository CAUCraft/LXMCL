# LXMCL UI

从当前 Slint 实现继续迭代。仓库根目录是本技能目录的 `../../..`；链接均相对于此文件，可直接随仓库使用。

## 开始工作

先读 [开发交接](../../../docs/development.md) 和 [验证记录](../../../docs/validation.md)，确认真实能力、演示部分和待复验项。根据任务选择参考，不必加载所有文档：

- 功能分组、入口、需求覆盖：[信息架构](../../../docs/ui/information-architecture.md)。
- 视觉、主题、玻璃、皮肤或视频：[视觉与动效](../../../docs/ui/visual-design.md)。
- 按钮、防呆、首次游玩或教程：[交互规范](../../../docs/ui/interaction.md)。
- 检查、准备、错误、请求与后端接入：[接口与状态](../../../docs/ui/service-contracts.md)，并核对 `src/contracts.rs`。

## 保持设计意图

项目追求自维护实现的 Rust 单语言，Slint 被明确允许。第三方内部语言不限；已有历史脚本不代表可以为新功能增加 JS / Python 运行链。UI 已转向直接写 Slint，不默认回 Figma，也不调用 Figma AI 生成设计。

这是 Minecraft 社团产品，身份来自原始 Logo 与孪枭，不推导航空或航天主题。经典与像素玻璃共享信息架构；切换风格保留上下文。玻璃本体也要有阶梯像素轮廓，不能只给圆润玻璃配几个像素图标。正文保持可读中文，不强制像素字体。

优先使用 `ui/components.slint` 与 `ui/theme.slint`，不要在页面硬编码第二套主题。浅深切换沿统一 `Theme.darkness` 插值；动态素材与视频下优先保证文字和焦点可读。当前不存在实时模糊或折射，不夸大效果。

孪枭用 `ui/assets/luanxiao.png`，是双层 64 × 64 RGBA 经典手臂皮肤。旧 `club-skin.png` 无透明通道，不得替换回来。原 Logo / 皮肤不重绘、不抠白；双层 UV、外扩和头部转轴约束见视觉文档。

## 维护交互与响应速度

让页面立即响应，动画仅追随最新目标：导航融合 280 ms，明暗切换 360 ms。不要排队播放、不在静止时维持动画计时器；孪枭按需刷新，壁纸后台解码只保留最新帧。维护 `VecModel` 身份，更新变化行。对真实 I/O 建工作线程桥，不能放入 Slint 回调。

动作名称表达对象与结果；重要对象、路径和来源在确认前可见。教程和错误帮助保留原任务上下文。未知结果不等于通过，缺环境 / 账号过期 / 不兼容提供不同修复路径。删除与覆盖清楚表达对象和影响，不把危险动作做成默认主按钮。

准备流程绑定 `LaunchContext` 与修订。检查失败清除旧报告，提交前拒绝过期计划；重复请求保持幂等，失败重试沿用原请求身份。当前请求是内存演示，不把就绪 badge、固定计时器或路径语法检查描述为真实认证、下载、空间 / 权限检测。

## 完成与交接

按改动选择验证：契约改动测试旧结果、目标固定和重试；视觉改动检查实际窗口和键盘焦点。对性能改动使用同场景报告，不把 CPU 耗时当端到端延迟。Windows 重新链接前关闭运行中的程序；详细命令见开发交接。

同步更新与改动相关的单份规范和验证记录，明确尚未实现 / 尚未检查的部分。归档 Figma 图不能冒充当前界面截图。新增素材保留来源、遵守 LFS；技能本身不授予向外部服务发布或修改权限。
