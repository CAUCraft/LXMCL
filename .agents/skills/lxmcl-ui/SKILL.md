## 实施约束

- 四主 Tab：主页 / 版本 / 联机 / 设置，右上账号。非首页共用一条上下文栏；实例详情替换列表和分类；设置统一八类。
- 内部页面使用 44px 上下文栏、32px 普通控件、64px 实例行和对齐的属性表；不使用整页位移入场。单击选择、Enter / 双击管理、F2 重命名；浏览实例与首页启动目标独立。
- 社团服务后续通过插件实现，默认联机页仅显示未启用状态；不提供社团演示服务器、进服或公告流程。创建实例只保存配置，空态直接进入创建表单。
- 河谷首页右下只有版本选择、绿色启动、文件夹、实例设置。正常首页无标题、存档切换、就绪、新闻或常驻状态；真实问题提供对应修复入口。
- 版本标签不是 ID；完整实例候选独立于搜索。准备报告绑定实例、账号、目录和修订，不复用过期目标。
- Windows 将窗控合入现有导航顶栏，不再叠加独立系统标题栏；品牌与空白处拖动、双击最大化，交互控件不参与拖动。其他平台保留系统装饰回退。窗控及缩放须实测，不使用 macOS 三色窗控或整张 UI 贴图，不虚构系统 Mica。
- 原 Logo / 孪枭皮肤字节不变；动态壁纸可选，不删素材、功能、安全流程和稳定教程 ID 来简化界面。
- 默认 Shell 提供共享控件、导航、焦点、浮层和动效；插件贡献语义内容，整套 Shell 可替换。Slint 类型留在 Shell。
- 动画只追随最新目标，退场层最多一个，减少动态效果立即清理，闲置停表；列表增量更新，阻塞 I/O 走后台。
- 演示认证、下载、安装、启动与诊断不冒充真实成功；UI 不推断服务尚未提供的能力。

## 工作方式

1. 检查源码与未提交变更，按任务范围调整；新入口覆盖全部功能后再移除旧兼容实现。
2. 优先修改 `ui/theme.slint`、`ui/components.slint` 共享定义；Shell 管导航 / 浮层，页面管内容，Rust 展示层映射业务状态。按架构设计逐步迁移，不能把未实现的分层写成现状。
3. 根据涉及的控件处理键盘、焦点、禁用、忙碌、错误、空态、暗色及减少动态效果，保持草稿、列表返回位置和目标身份连续。
4. 按实际风险检查。文档改动验证引用；Rust / Slint 改动选择相关编译、测试和窗口核对。不要重复测试、镜像实现写测试或添加假设性防御分支。
5. 结果写在交付说明或 PR；截图和测量写入 `target/`，本机工作笔记写入 `.local/`。未实测的 DPI、读屏、系统窗口与流畅度如实说明，不新增公开验证流水账。

用户最新决定优先于正式设计；其他参考保留业务需求，不恢复旧侧栏或像素玻璃视觉基线。
